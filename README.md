# radio-agent

Autonomer Radio-Betrieb: Raspberry Pi 4 + OpenWebRX+ (`owrx-mbe`).
MCP-Agent verbessert Radio, sammelt Content (Fax/Audio), recherchiert
deutsche Sendezeiten, plant Aufnahmen per Cron. Anzeige via Handy-WebApp.

Start: `spec.md`, Tickets unter `issues/`, erste WS-Probe in `probe.py`.
